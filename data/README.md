# Data

The SQL analysis expects two MySQL tables:

- `king`: order-level transaction, customer, product, date, status, payment, discount, and seller-ID fields
- `seller`: seller-ID and seller-name lookup fields

The original raw dataset is not included in this repository package because it was not available as a local file during packaging. Load your own authorized copy into MySQL before running the SQL file. Do not commit credentials, private customer data, or restricted source data.
